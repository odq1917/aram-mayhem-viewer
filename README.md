# ⚔️ MAYHEM.GG - 롤 증강 칼바람(아수라장) 전적 검색기

롤 클라이언트 내부 API(LCU)를 활용하여, 일반 전적 사이트에서 누락되거나 확인하기 어려운 **증강 칼바람(아수라장)의 매치 기록, 장착 증강체(실버/골드/프리즘), 챔피언별 승률·통계, 10인 딜량 및 아이템 빌드**를 완벽하게 조회하고 영구 누적 저장하는 로컬 웹 대시보드입니다.

---

## 📦 다운로드 및 실행 방법 (일반 사용자용 - Node.js 설치 불필요)

1. 우측 **[Releases](../../releases)** 페이지에서 최신 **`ARAM-Mayhem-Viewer-Portable-v1.5.3.zip`** 파일을 다운로드합니다.
2. 원하는 폴더에 압축을 해제합니다.
3. **리그 오브 레전드(LoL) 클라이언트**를 실행하고 로그인합니다.
4. 폴더 내 **`start.bat`** 파일을 더블 클릭하면 서버가 **창 없이 백그라운드로** 실행되고 대시보드(`http://localhost:3500`)가 열립니다.
5. *(선택)* 대시보드 우측 상단의 **[북마크 추가]** 버튼을 눌러 브라우저 북마크바에 등록해 두면, 다음부터는 `start.bat`을 켜지 않고도 **북마크 클릭 한 번으로 서버 자동 실행 + 전적 조회**가 가능합니다.
6. 대시보드 페이지를 모두 닫고 **1시간**이 지나면 서버가 자동으로 종료됩니다. 바로 끄려면 **`stop.bat`**을 실행합니다. 실행 로그는 `run_log.txt`에 남습니다.
7. 새 버전이 나오면 화면 상단 버전 옆에 **[새 버전]** 배지가 표시됩니다. (버전을 클릭하면 바로 다시 확인) 새 zip을 받아 아무 폴더에나 풀고 `start.bat`을 실행하면 됩니다. 누적 전적은 프로그램 폴더가 아닌 **`%APPDATA%MAYHEM.GG`** 에 저장되므로 복사할 필요가 없습니다. (v1.3.0 이하에서 넘어올 때만, 이전 폴더의 `data/history`·`data/recent_searches.json`을 새 폴더의 `data/`에 한 번 복사하면 첫 실행 때 자동으로 옮겨집니다)

## 🌟 주요 기능

1. **내 전적 자동 연동 & 소환사 검색**:
   - 롤 클라이언트에 로그인된 내 계정을 자동 인식하며, `소환사명#태그` 검색 및 최근 검색어 칩을 지원합니다.
2. **과거 전적 영구 누적 & 지능형 이어붙이기 (Stitching)**:
   - 롤 클라이언트에서 사라지는 과거 전적들을 로컬에 자동 누적 저장합니다.
   - 미기록 공백 구간이 있을 경우 `··· 이 사이의 미기록 경기 존재 ···` 구분선으로 직관적으로 표시합니다.
3. **챔피언별 검색 & 상단 통계 실시간 재계산**:
   - 챔피언 이름 또는 초성(`ㅈㅋㅅ` → `징크스`)으로 검색하거나, 내가 플레이한 챔피언 드롭다운(판수·승률순)에서 선택할 수 있습니다.
   - 챔피언 선택 시 상단 **승률, 평균 KDA, 최다/현재 연승·연패, 해당 챔피언 선호 증강체**가 즉시 그 챔피언 기준으로 재정렬됩니다.
4. **증강체 실시간 필터링 & 한국어 상세 툴팁**:
   - 실버 / 골드 / 프리즘 증강체 아이콘에 마우스를 올리면 세부 수치와 효과가 하이라이팅된 한국어 툴팁이 즉시 표시됩니다.
   - 완성된 한글 음절 기준 초고속 DOM 캐싱 필터링으로 수백 게임이 누적되어도 버벅임 없이 즉시 검색됩니다.
5. **10인 상세 딜량(물리/마법/고정) · 피해량 · 회복량 비교**:
   - 매치 카드를 클릭하면 양 팀 10명의 증강체, KDA, 딜량 비중 바, 아이템을 한눈에 비교할 수 있습니다.
6. **증강체 도감 (Augment Codex)**:
   - 아수라장에 등장하는 전체 증강체를 등급별·키워드별로 검색할 수 있습니다.
7. **오프라인 열람**:
   - 롤 클라이언트가 꺼져 있어도 최근 검색한 소환사의 저장된 전적을 볼 수 있습니다.
8. **전적 갱신 & 게임 종료 자동 갱신**:
   - 게임이 끝나면 자동으로 최근 경기를 불러와 화면에 반영합니다. 프로필 카드의 [전적 갱신]으로 직접 갱신할 수도 있습니다.
   - **자동 갱신 목록**: 다른 소환사 프로필의 [☆ 자동 갱신]을 누르거나 데이터 폴더의 `auto-refresh.txt`에 `닉네임#태그`를 적어 두면, 전적 검색기를 켤 때와 게임이 끝날 때마다 함께 갱신해 오래된 경기도 빠짐없이 쌓입니다.
9. **상세 창에서 소환사 바로 검색**:
   - 10인 상세 창의 다른 소환사 닉네임을 클릭하면 그 소환사의 전적으로 이동합니다.
10. **통계**:
   - 증강별 선택 수·승률, 같은 팀으로 자주 함께한 소환사와의 승률, 패치별 승률을 볼 수 있고, 상단에 이번 패치 승률이 표시됩니다.
   - 경기 카드에 최다 멀티킬(더블킬~펜타킬)이 표시됩니다.
11. **증강 출처 표시 & 아레나 제외**:
   - 롤 전적에는 레벨 3·7·11·15에 고른 증강만 기록되고, 전환(골드/프리즘/혼돈)이 준 증강은 남지 않습니다. 예외로 기록되는 **나는 왕이다 보상(👑)** 과 **전환이 뽑아 준 전환류 증강(↳)** 을 표시하고, 툴팁에 안내를 보여줍니다.
   - 아레나 경기는 다루지 않습니다. (불러오거나 저장하지 않습니다)

## 🛠️ 개발자 / 소스코드 실행 방법 (Node.js 설치 환경)

```bash
npm install
npm start
npm test   # 전적 병합(공백 판정) 로직 테스트
```
브라우저에서 `http://localhost:3500`으로 접속합니다.

> 서버는 `127.0.0.1`에서만 열리며, 대시보드 외 다른 웹사이트의 API 호출은 차단됩니다.
